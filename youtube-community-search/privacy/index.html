Privacy Policy — YouTube Community Search

Last updated: August 2, 2026

What the extension stores

Imported community post data (text, metrics, and related fields from YouTube Studio Analytics or a Studio zip) is stored locally in your browser using Chrome extension storage. Your Channel ID, if saved, is also stored locally so the extension can open the correct Studio Analytics page.

This data is not uploaded to the developer’s servers for normal use.

Reliability diagnostics (Formspree)

On rare sync failures or unexpected Studio Analytics response shapes, the extension may send a small anonymous reliability report to Formspree so the developer can fix compatibility issues quickly.

That report may include:

  • Error codes and a short technical message
  • Extension version
  • Coarse counts such as how many posts or metric rows were parsed

It does not include:

  • Post text or images
  • Your Channel ID
  • Cookies, passwords, or Google account credentials
  • Your email address

Reports are rate-limited (at most once per error type per day on a given install).

Basic usage analytics

The extension may send anonymous product usage events (for example: extension opened, sync started, sync finished, upgrade button clicked) using Google Analytics Measurement Protocol. Events include only technical fields such as event name, extension version, and an anonymous install id. They do not include post text, Channel IDs, cookies, tokens, or email addresses.

Permissions (why they exist)

  • storage / unlimitedStorage — save your post library locally
  • tabs — open/focus Studio Analytics and the status window during import
  • notifications — optional desktop notices for import progress
  • Host: studio.youtube.com — run import helpers on YouTube Studio Analytics
  • Host: formspree.io — send the anonymous reliability reports described above
  • Host: google-analytics.com — send anonymous usage events only
